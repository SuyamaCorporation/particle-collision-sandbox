# Particle Collision Sandbox

**Category:** Physics Simulation

Interactive particle physics sandbox with 6 particle types: Matter+/-, Antimatter+/-, Neutron, and Heavy (graviton). Toggleable physics rules include matter/antimatter annihilation (spawns gamma rays), electromagnetic attraction/repulsion, gravitational wells from heavy particles, quantum tunneling, and particle decay. Click canvas to spawn particles, watch collision events and annihilation explosions.
